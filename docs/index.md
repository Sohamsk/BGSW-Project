# VB6 To C# Migration Tool

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)

> A modern tool for migrating legacy VB6 applications to C# .NET.

## Overview

This documentation provides comprehensive information about the VB6 to C# Migration Tool, which offers an effective solution for updating legacy VB6 applications to modern C# .NET platforms.

## Features

- **Automated Code Conversion**: Convert VB6 code to equivalent C# syntax
- **Type Mapping**: Intelligent mapping between VB6 and C# data types
- **Control Flow Conversion**: Accurate translation of control structures
- **Easy to Use**: Simple command-line interface
